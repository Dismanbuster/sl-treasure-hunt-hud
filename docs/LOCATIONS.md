# Treasure Hunt Locations

## Location Format
Each location entry contains:
- **Region Name**: The SL region where treasure is hidden
- **Search Criteria**: The object name/keyword to search for (case-insensitive)
- **XP Reward**: Points awarded for finding this treasure
- **Season**: "all" for always available, or "halloween", "christmas", "easter", "summer"

## Adding New Locations

1. Place a prim in your chosen location
2. Rename it to your search criteria (e.g., "Pumpkin", "Wreath", "Egg")
3. Add an entry to the locations list in the HUD script
4. Tag with appropriate season
5. Test by visiting that region

## Seasonal Hunts

### Halloween (Oct 1 - Oct 31)
- Search for festive decorations
- Higher XP rewards

### Christmas (Dec 1 - Dec 25)
- Winter/holiday themed treasures
- Special bonus XP

### Easter (Apr 1 - Apr 30)
- Egg hunts
- Spring themed items

### Summer (Jun 1 - Aug 31)
- Beach/water themed treasures
- Outdoor items
